# Descriptive Statistics Analyzer

A Python-based tool for performing descriptive statistical analysis on datasets. It helps analyze data, understand distributions, summarize numerical variables, and generate visualizations for exploratory data analysis.

## Features

- Automated descriptive statistical analysis
- Dataset exploration and summary statistics
- Statistical measures for numerical data
- Data visualization and graphical analysis
- Modular project structure
- Report generation and organized output folders
- Terminal-based interactive application

## Project Structure

```text
Descriptive_Statistics_Analyzer/
│
├── main.py
├── modules/
├── visualizations/
├── reports/
├── .gitignore
└── README.md
```

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/Descriptive-Statistics-Analyzer.git
```

Navigate to the project folder:

```bash
cd Descriptive-Statistics-Analyzer
```

Install dependencies (if a requirements.txt is provided):

```bash
python -m pip install -r requirements.txt
```

## Usage

Run the application from the terminal:

```bash
python main.py
```

Follow the interactive prompts to perform descriptive statistical analysis.

## Output

The application organizes generated reports and visualizations into dedicated folders for easier access and review.

This project was developed to practice Python programming, statistical analysis, data exploration, modular development, and automated reporting.
